What this pilot proves — and what it does not

Uses the actual game's camera helper, near-plane convention and opaque pixel-depth code. Scene geometry is an authored chest-shaped proxy and a room corner, not the production chest renderer or the future object system. Face lighting and distance fog are fixed study settings, not the complete game light pipeline. No physics, AI, saves, device APIs or gameplay randomness run here.

Opaque tiles only. Screen-clipped adaptive triangles approximate perspective with a 0.65-pixel target, maximum 256 triangles per face and 2,048 per view. Budget-limited faces are counted; exhausted faces retain their solid fallback. The error target is not guaranteed when the cap is reached. Texture triangles overlap inside an exact opaque depth mask. Anti-shimmer uses precomputed mip levels and at most two cached pattern fills per triangle. It can soften grazing surfaces; it does not solve every perspective or subdivision artifact.

Benchmark locks the controls and uses the selected tile size, filtering, anti-shimmer, surface, chest size, lid and pillar settings; it always replays the room camera. Each run has 30 warm-up frames and 180 measured frames. Results include per-stage percentiles, actual pattern fills, submitted work, cadence and 60/120 Hz submission-budget exceedances. Keep the page visible; hidden-page runs abort. Browser backing stores and pattern caches are not included in the stated raw texture byte count. This is not a low-end-device certification.
