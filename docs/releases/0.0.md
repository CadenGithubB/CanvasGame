# CanvasGame 0.0

Initial standalone development snapshot, dated 2026-09-27. The release tag is
`v0.0`; `VERSION` contains `0.0`. This is a preservation/migration release, not
a new renderer or an assertion that all game defects are fixed.

## Included

- All editable game fragments, markup, styles, manifest, and generated header.
- Game artwork, procedural texture recipes, prepared-filter implementation,
  isolated material/structure previews, and recorded visual-test evidence.
- Shared physics/spatial, fixed-tick/interpolation, NPC AI, rendering, and
  gameplay regressions, including the extended audit lab and mutation controls.
- Game development/testing docs, design plans, and sanitized historical audit
  reports. Earlier instructions to keep the lab local are superseded by this
  standalone publication. Historical failures remain recorded as failures.

The legacy directory layout is retained to avoid changing gameplay, test paths,
or assembly semantics during extraction. The original HardwareOne working copy
is preserved; unrelated firmware, private device data, caches, and Git history
are not imported. The existing license is unchanged.

## Known rendering limitations

- The structure preview's default 2,048 triangle-plus-strip budget is consumed
  in draw order. At the arena exterior's distance -45 view with directional
  mapping, the captured 360x240 workload reached 2,048 strips and left 295
  faces on their solid fallback. A fortress roof view also reproduced budget
  starvation. This is not an arena-only problem or persistent texture damage.
- Higher diagnostic budgets restore coverage but increase work. LOD,
  coverage-first allocation, and selective sampling quality are plans only.
- Directional planar mapping remains experimental and opt-in. Its 20 selected
  structure-motion cases passed; the triangle comparison retains eight quality
  failures. Those fixtures do not certify the full zoom range or default-budget
  coverage. The floor-walk pass has little margin below its threshold.
- Three historical readback-optimized long-line cases still report setup/sample
  failures from native compositing differences. Those were not silently waived.
- Native Canvas submission timings are not GPU completion or whole-game FPS.
  See `tools/game/TEXTURES.md` and its retained JSON evidence for exact scope.

## Verification and evidence

The core 160-test gate passes. The extended audit reports eight failing
assertions (including stale historical expectations and fixture setup failures)
and 207 opt-in skips. These were not converted into expected passes. See the
validation record for the exact affected suites and pending investigation.

The migration verification results are recorded in `VALIDATION-0.0.md` alongside
these notes. Historical lab captures refer to earlier source snapshots and are
not current goldens. Sanitization replaces workstation/user-specific paths and
session locations; the original private copies remain outside this repository.

Public license attribution is retained. Commit/tag identity uses a nonpersonal
project identity; credentials and personal workstation metadata are excluded.
