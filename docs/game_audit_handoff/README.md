# Historical game audit and design records

These game-specific records are included in CanvasGame 0.0 at the owner's
request. They document earlier investigations and may describe older code,
known failures, discontinued workflows, or proposals rather than current
behavior. Current guidance lives in the root `AGENTS.md`, `assets/games/`, and
the release notes.

Statements in old records that the lab/handoff must stay local describe the
previous repository agreement; they are superseded for these reviewed files.
Local usernames, workstation paths, and session locations have been sanitized.
Archived command excerpts are evidence, not instructions to execute blindly.
Run the maintained `tools/game/` and `tools/webui/` suites for current checks.
